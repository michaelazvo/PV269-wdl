# hello-world-wdl

A minimal "Hello, World" WDL 1.0 workflow, set up for Dockstore and Terra.

- `hello-world/hello-world.wdl` – workflow and task
- `hello-world/hello-world.inputs.json` – example inputs
- `.dockstore.yml` – Dockstore registration config

Run locally: `miniwdl run hello-world/hello-world.wdl -i hello-world/hello-world.inputs.json`
